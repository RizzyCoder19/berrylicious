Study the reference image for:

-   decorative doodles

The written PRD defines **what the website contains**.

and feel**.

# 2. DESIGN NORTH STAR

The visual goal is:

> **Berry café × cute stationery × modern dessert brand × playful
> startup**

The website should feel:

-   cute
-   fresh
-   handcrafted
-   premium-but-accessible
-   warm
-   youthful
-   playful
-   memorable
-   commercially believable

The final reaction should be:

> "This looks like a real dessert brand."

Not:

> "This looks like a school project."

And not:

> "This is an AI-generated restaurant template."

------------------------------------------------------------------------

# 3. DESIGN PRINCIPLES

## 3.1 Cute, not childish

Use:

-   rounded forms
-   playful typography
-   illustrated berries
-   tiny doodles
-   soft colors
-   friendly details

Avoid:

-   excessive cartoon styling
-   childish clip-art
-   giant emoji
-   rainbow palettes
-   toy-like UI

## 3.2 Premium, not luxury

The brand should feel polished without becoming an expensive fine-dining
brand.

Use:

-   strong typography
-   clean spacing
-   restrained shadows
-   intentional composition
-   quality product visuals

Avoid:

-   black-and-gold luxury aesthetics
-   excessive glassmorphism
-   metallic effects
-   overly formal layouts

## 3.3 Playful, not chaotic

"Chaos" is part of the brand personality, but the interface itself must
remain organized.

Use controlled asymmetry and playful decoration.

Never sacrifice usability for personality.

------------------------------------------------------------------------

# 4. COLOR SYSTEM

Use these exact base colors unless there is a strong design reason to
create a derived shade.

  Token                Name               Hex
  -------------------- ------------------ -----------
  `berry-pink`         Berry Pink         `#E98FA8`
  `deep-berry`         Deep Berry         `#9E4663`
  `strawberry-cream`   Strawberry Cream   `#FFF1E8`
  `vanilla`            Vanilla            `#FFF9F0`
  `mint`               Mint               `#BFE9DE`
  `soft-blue`          Soft Blue          `#B8DDF2`
  `dark-cocoa`         Dark Cocoa         `#382D32`

## Color hierarchy

Recommended visual ratio:

-   Vanilla / cream: dominant
-   Strawberry Cream: secondary background
-   Berry Pink: primary action/accent
-   Deep Berry: strong headings and mature business sections
-   Mint: fresh/natural accents
-   Soft Blue: secondary playful accents
-   Dark Cocoa: body text

Do not make the entire website pink.

------------------------------------------------------------------------

# 5. TYPOGRAPHY

Use two complementary families.

## Display

A playful handwritten/script-style font.

Use for:

-   major decorative headings
-   selected product names
-   brand moments
-   short phrases

The script should resemble the friendly handwritten quality shown in the
reference image.

## Body

A modern rounded sans-serif.

Use for:

-   body copy
-   navigation
-   pricing
-   buttons
-   labels
-   business figures
-   financial information

### Hard rule

Never use the script font for:

-   long paragraphs
-   pricing
-   financial figures
-   important navigation
-   dense information

# 6. LOGO DIRECTION

The Berrylicious wordmark should be the primary identity.

The reference image demonstrates a playful handwritten Berrylicious
wordmark with berry/leaf decoration.

Use a clean primary wordmark.

Possible supporting marks:

-   strawberry icon
-   "B" monogram
-   circular badge
-   favicon

Do not introduce "Dolce and Chaos" anywhere.

Do not reuse the old brand name.

# 7. ILLUSTRATION LANGUAGE

Illustrations should feel:

-   hand-drawn
-   soft
-   rounded
-   slightly imperfect
-   friendly
-   pastel
-   expressive

Preferred subjects:

-   strawberries
-   blueberries
-   raspberries
-   dessert cups
-   gelato
-   waffles
-   pancakes
-   cakes
-   cherries
-   leaves
-   bows
-   hearts
-   stars

Use a consistent stroke/outline language.

Do not mix:

-   realistic stock photography
-   unrelated cartoon styles
-   random vector packs

in the same visual system.

------------------------------------------------------------------------

# 8. PRODUCT VISUAL STYLE

Product imagery should be appetizing while retaining the Berrylicious
aesthetic.

Preferred composition:

-   creamy/pastel background
-   strong dessert subject
-   fresh berries
-   natural highlights
-   subtle illustrated accents
-   clean composition

Product images should feel like premium food-brand
photography/illustration rather than supermarket catalog shots.

If real product photos are unavailable:

Use a consistent illustrated/product-art direction.

Do not mix random placeholder images.

------------------------------------------------------------------------

# 9. HERO DESIGN

The hero should be the strongest visual section.

Suggested composition:

Left:

-   eyebrow
-   large headline
-   supporting text
-   CTA buttons

Right:

-   hero dessert composition
-   berries
-   cream
-   dessert cup
-   decorative doodles

On mobile:

-   headline remains dominant
-   product composition moves below/around the headline
-   decorative elements are reduced
-   buttons remain easy to tap

The reference image's hero composition should guide the visual balance.

------------------------------------------------------------------------

# 10. DECORATIVE LANGUAGE

Use small visual details:

-   hand-drawn hearts
-   stars
-   berry sketches
-   tiny flowers
-   leaves
-   ribbons
-   curved underline strokes
-   small handwritten notes

Examples of decorative phrases:

-   "Scoop happiness"
-   "Good vibes"
-   "Sweet moments"
-   "A little chaotic"

These should be used sparingly.

Do not fill every empty space with decoration.

------------------------------------------------------------------------

# 11. CARDS

Product cards should have:

-   rounded corners
-   cream/white surfaces
-   subtle borders
-   soft shadows
-   product image
-   product name
-   descriptors
-   price
-   action

Cards should feel tactile.

Desktop hover:

-   slight lift
-   image scale approximately 1.03
-   small decorative reveal

Mobile:

-   no hover dependency

------------------------------------------------------------------------

# 12. BUTTONS

Primary CTA:

Berry Pink background\
White text

Secondary CTA:

Cream/white background\
Deep Berry border/text

Button shape:

-   rounded/pill-like
-   comfortable padding
-   clear hover state

Motion:

-   subtle lift
-   tiny scale
-   no exaggerated bounce

------------------------------------------------------------------------

# 13. SECTION TRANSITIONS

The page should feel like one continuous visual story.

Use:

-   soft background changes
-   curved section boundaries
-   small doodles
-   overlapping illustrations
-   subtle decorative elements

Avoid hard boxed sections stacked like a dashboard.

Business/financial sections may become visually more structured and
mature.

------------------------------------------------------------------------

# 14. CRAVING SELECTOR

The selector should look like a playful menu of moods.

Categories:

-   Fruity
-   Creamy
-   Indulgent
-   Fluffy

Each category can have:

-   illustrated icon
-   soft pastel circular/rounded background
-   short label

Active state:

-   Berry Pink accent
-   slightly stronger border
-   subtle scale/motion

The reference image's category-icon treatment should guide the
implementation.

------------------------------------------------------------------------

# 15. DESSERT BUILDER

This is the visual centerpiece of the interactive experience.

The reference image includes a conceptual builder.

Use that as visual inspiration.

The builder should feel like a playful customization interface rather
than a generic ecommerce configurator.

Structure:

``` text
Build Your
Berrylicious

01 Base
02 Flavour
03 Topping
04 Your Creation
```

Use illustrated option cards.

Selected option:

-   Berry Pink border
-   subtle glow/shadow
-   clear selected state

Final creation:

-   large dessert visual
-   ingredient summary
-   price
-   CTA

Keep the layout simple enough to operate live during a presentation.

------------------------------------------------------------------------

# 16. MENU DESIGN

The menu should combine the visual language of the supplied reference
menus with modern web usability.

Use:

-   category sections
-   product cards
-   clear pricing
-   small descriptors
-   filter/selector where useful

Do not reproduce the reference menu as a scanned menu.

Translate its aesthetic into a modern responsive interface.

# 20. BACKGROUND TEXTURES

The reference image uses playful patterns.

Possible textures:

-   strawberry repeats
-   tiny berries
-   leaves
-   hearts
-   bows
-   subtle gingham
-   small stars

Use textures at very low visual intensity.

Never let background patterns interfere with readability.

------------------------------------------------------------------------

# 21. SPACING

Use generous spacing.

The website should breathe.

Avoid:

-   cramped cards
-   tiny typography
-   excessive content per viewport
-   every section touching the next

Use a consistent spacing scale through Tailwind design tokens.

------------------------------------------------------------------------

# 22. SHADOWS

Use soft shadows only.

Preferred:

-   low opacity
-   large blur
-   subtle offset

Avoid:

-   heavy black shadows
-   neon glow
-   dramatic floating effects

------------------------------------------------------------------------

# 23. BORDERS

Use:

-   soft berry borders
-   subtle cocoa borders
-   occasional dashed/hand-drawn-inspired borders

Borders should support the stationery/handcrafted feel.

Do not put borders around everything.

------------------------------------------------------------------------

# 24. RESPONSIVE VISUAL RULES

## Desktop

More expressive compositions.

Allow:

-   overlapping illustrations
-   asymmetric hero
-   multi-column menu
-   larger decorative elements

## Tablet

Reduce decoration and preserve hierarchy.

## Mobile

Prioritize:

1.  headline
2.  product
3.  CTA
4.  interaction

Reduce:

-   decorative clutter
-   large background illustrations
-   excessive horizontal movement

The mobile version should feel intentionally designed, not compressed.

------------------------------------------------------------------------

# 25. MOTION DIRECTION

Animation should feel:

**soft, organic, delicious, slightly playful**

Use:

-   fade
-   slide
-   scale
-   gentle float
-   subtle parallax
-   layout transitions

Avoid:

-   bouncing everything
-   spinning everything
-   flashy page transitions
-   aggressive zoom
-   cursor-following effects everywhere

Motion should communicate:

**freshness + playfulness**

not technical complexity.

------------------------------------------------------------------------

# 26. IMAGE + ILLUSTRATION CONSISTENCY

Every visual asset must feel as if it belongs to the same brand.

Before adding an image ask:

> Would this look natural next to the supplied Berrylicious reference
> image?

If no, do not use it.

Avoid combining:

-   realistic stock photos
-   generic AI art
-   flat corporate icons
-   unrelated illustrations

without a deliberate treatment that unifies them.

------------------------------------------------------------------------

# 27. DESIGN ANTI-PATTERNS

Do not create:

-   generic restaurant templates
-   black luxury dessert websites
-   all-pink websites
-   excessive glassmorphism
-   excessive gradients
-   neon colors
-   giant food emojis
-   random stock photos
-   giant 3D strawberries
-   particle backgrounds
-   over-animated cursors
-   fake Instagram feeds
-   fake reviews
-   fake awards
-   fake customer statistics
-   fake social proof

------------------------------------------------------------------------

# 28. VISUAL HIERARCHY

Every viewport should have one obvious focal point.

For the hero:

**Berrylicious headline + dessert**

For the menu:

**Product + price**

For the builder:

**Current creation**

For the business section:

**Key numbers**

For the investment section:

**₹20 LAKH for 10% equity**

Do not make every element equally loud.

------------------------------------------------------------------------

# 29. PRESENTATION-FIRST DESIGN

The website will be shown live to judges.

Therefore:

-   CTAs must be obvious.
-   Navigation must be fast.
-   Builder must be easy to operate.
-   Financial numbers must be readable from a distance.
-   Animations must not delay the presenter.
-   Avoid loading states during normal interaction.
-   Avoid external APIs.

The website should look impressive even when viewed from a classroom
projector.

------------------------------------------------------------------------

# 30. DESIGN QA CHECKLIST

Before finalizing, compare the implementation against the supplied
reference image.

Check:

### Brand

-   Does it clearly read as Berrylicious?
-   Is the logo treatment consistent?
-   Is the visual personality coherent?

### Color

-   Is cream dominant?
-   Are berry pink/mint/blue accents balanced?
-   Is it avoiding an all-pink appearance?

### Typography

-   Is script used selectively?
-   Is body text highly readable?
-   Are financial figures clean and professional?

### Illustration

-   Are berry/dessert illustrations stylistically consistent?
-   Do decorative elements feel handcrafted?

### Layout

-   Does the site breathe?
-   Are sections visually connected?
-   Does it avoid generic restaurant-template structure?

### Interaction

-   Does the builder feel delightful?
-   Are states obvious?
-   Are transitions subtle?

### Presentation

-   Can Tanvi navigate the important sections quickly?
-   Can a judge understand the business numbers immediately?
-   Does the site remain impressive without animation?
